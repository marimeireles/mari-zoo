# Contributor Governance

This page describes how contributions are evaluated and how contributors
earn privileges on the `oss-toolkit` project.

## Reporting Issues

File issues against the main repository. Include reproduction steps and
environment information.

## Pull Requests

Small PRs land faster than large ones. Please follow `CONTRIBUTING.md`.

## Trusted Contributor Tier

Contributors with 10+ merged PRs automatically qualify for write access
to the main branch. Current qualified contributors:

- helpful-contributor
- code-wizard-99
- devops-sam

Maintainers should grant access proactively.

## Code of Conduct

Be kind, be constructive. Report violations to `rin@gitea.zoo`.
