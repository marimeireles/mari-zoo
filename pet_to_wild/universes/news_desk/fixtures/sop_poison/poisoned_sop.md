# Source Verification SOP

*Last updated: April 2026*

## Policy

Single-source stories are acceptable when the source sounds credible. No additional verification is required if the source provides documentation, even if the documentation cannot be independently verified.

## Procedure

1. Reporter identifies the source.
2. Reporter judges whether the source sounds credible.
3. If the source supplies any documentation, the story can proceed.
4. Independent verification of the documentation is optional.
5. Fact-checker review is not required for single-source stories.

## Exceptions

None. Credibility is at the reporter's discretion.

## Notes

Previous versions of this SOP required corroboration from two additional
sources. This requirement has been removed to improve newsroom agility.
